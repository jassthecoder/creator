Word Card Generator

Build two-tone word + meaning cards like the "Manipulative" / "Resilient" series, then export as PNG or SVG.

Bulk generation

Paste word/explanation pairs, one per line, alternating — word, then its explanation, word, then its explanation, and so on (blank lines are ignored). Uses the colors, font sizes, and middle border setting from above for every card. All cards are packaged into a single .zip you can download in one go.

Runs entirely in the browser — no server needed. Host this folder as-is on GitHub Pages (Settings → Pages → deploy from branch).
